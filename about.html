About Me

Software Engineer • SQL Server • VB6 • ERP • Technology

Yusep Lukman

Saya adalah seorang Software Engineer yang telah bekerja di dunia teknologi informasi selama lebih dari 18 tahun. Perjalanan saya di dunia IT dimulai sejak tahun 2007 dan sampai sekarang masih terus berhubungan dengan software development, database, ERP, system analysis, troubleshooting, dan berbagai kebutuhan teknologi di lingkungan perusahaan.

Selama bertahun-tahun bekerja sebagai developer, saya banyak menggunakan teknologi yang mungkin bagi sebagian orang sudah dianggap sebagai teknologi lama. Salah satunya adalah Visual Basic 6.

Namun bagi saya, teknologi lama bukan berarti teknologi yang tidak berguna. Banyak aplikasi bisnis yang sudah berjalan bertahun-tahun dan masih digunakan sampai sekarang. Aplikasi tersebut tetap membutuhkan maintenance, improvement, troubleshooting, dan integrasi dengan sistem yang lebih baru.

My Experience

Pengalaman saya banyak berkaitan dengan aplikasi bisnis dan Enterprise Resource Planning (ERP). Saya pernah terlibat dalam pengembangan dan implementasi sistem yang digunakan untuk mendukung proses bisnis perusahaan.

Saya terbiasa bekerja dengan database seperti Microsoft SQL Server, Oracle, Microsoft Access dan beberapa database lainnya.

Dalam pekerjaan sehari-hari, SQL Server menjadi salah satu teknologi yang paling sering saya gunakan. Mulai dari membuat query sederhana, stored procedure, reporting, data processing, troubleshooting database, sampai melakukan optimasi query ketika performa aplikasi mulai menurun.

Selain development, saya juga sering berada di posisi yang menghubungkan antara kebutuhan user dengan sisi teknis aplikasi. Karena itu saya cukup terbiasa membaca kebutuhan bisnis, menganalisis masalah, mencari akar permasalahan, kemudian menerjemahkannya menjadi solusi teknis.

Why I Created Yusep Notes

Yusep Notes dibuat sebagai tempat untuk menyimpan pengalaman, catatan, solusi dan pemikiran saya selama bekerja di dunia software engineering.

Banyak masalah yang saya temui dalam pekerjaan sebenarnya merupakan masalah sederhana, tetapi membutuhkan pengalaman untuk menemukan penyebabnya. Error database, query yang lambat, aplikasi lama yang tidak berjalan di Windows baru, masalah koneksi database, sampai bug kecil yang menghabiskan waktu berjam-jam.

Saya ingin menuliskan pengalaman tersebut supaya tidak hanya berhenti sebagai pengalaman pribadi. Mudah-mudahan catatan yang ada di website ini juga bisa membantu developer lain yang mungkin sedang menghadapi masalah yang sama.

AI and Software Development

Dunia software development sekarang berubah sangat cepat, terutama dengan hadirnya Artificial Intelligence.

AI dapat membantu developer membuat kode dengan jauh lebih cepat. Tetapi menurut saya, kemampuan membuat kode bukanlah satu-satunya kemampuan yang penting bagi seorang software engineer.

Developer tetap harus memahami database, business process, architecture, security, debugging dan konsekuensi dari kode yang dibuat.

Karena itu saya tertarik mempelajari bagaimana AI dapat digunakan sebagai alat bantu developer tanpa membuat developer kehilangan kemampuan untuk memahami apa yang sebenarnya terjadi di dalam sebuah aplikasi.

My Philosophy

"Coding is not only about writing code. It's about understanding the problem and building a solution that actually works."

Bagi saya, seorang software engineer tidak harus selalu menggunakan teknologi terbaru. Yang paling penting adalah memahami masalah, memilih teknologi yang tepat, dan membuat solusi yang dapat digunakan serta dipelihara dalam jangka panjang.

Teknologi akan terus berubah. Bahasa pemrograman akan berganti. Framework baru akan muncul. Tetapi kemampuan untuk berpikir logis, memahami masalah dan melakukan troubleshooting akan selalu dibutuhkan.

Keep Learning

Dari VB6 sampai teknologi modern, dari aplikasi desktop sampai web application, dari SQL Server sampai Artificial Intelligence — perjalanan sebagai software engineer tidak pernah benar-benar selesai.
